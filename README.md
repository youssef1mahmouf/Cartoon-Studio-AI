Cartoon Studio AI

## Overview\nCartoon Studio AI is a modular, scalable, and production-ready platform for creating animated cartoons from scripts. The system encompasses the entire production pipeline from script writing to final video rendering and export.

## Features\n\n### Core Functionality\n1. Project Management - Create and manage multiple projects\n2. Episode Management - Organize episodes within projects\n3. Script Writing - Write and edit scripts with AI analysis\n4. Script Analysis - AI-powered script analysis for scene and character extraction\n5. Scene Extraction - Automatic scene detection and numbering\n6. Character Extraction - Identify and catalog characters from scripts\n7. Prompt Generation - Generate character and background prompts using AI\n8. Image Generation - Generate characters and backgrounds using FLUX/SDXL\n9. Voice Generation - Generate character voices using Kokoro/TTS\n10. Scene Assembly - Build scenes with characters and backgrounds\n11. Rendering - Render final episodes using FFmpeg\n12. MP4 Export - Export final videos in MP4 format\n\n### AI Providers\n#### Text AI (OpenRouter)\n- DeepSeek V3\n- DeepSeek R1\n- Qwen\n- Llama\n- Gemma\n\n#### Image AI\n- Primary: Pollinations (FLUX, SDXL)\n- Backup: HuggingFace (FLUX, SDXL)\n\n#### Voice AI\n- Primary: Kokoro TTS\n- Backup: Piper TTS\n\n#### Video\n- FFmpeg for rendering and video processing\n

## Technology Stack\n\n### Frontend\n- Next.js 14 with App Router\n- React 18\n- TypeScript\n- TailwindCSS\n- Zustand (state management)\n\n### Backend\n- FastAPI (Python 3.11+)\n- SQLAlchemy (ORM)\n- SQLite (V1) / PostgreSQL (V2)\n\n### AI & Rendering\n- OpenRouter for text generation\n- Pollinations / HuggingFace for image generation\n- Kokoro / Piper for TTS\n- FFmpeg for video rendering\n\n### Infrastructure\n- SQLite for development (PostgreSQL ready)\n- Local file storage\n- FFmpeg for rendering\n

## Architecture\n\nCartoon Studio AI uses **Clean Architecture** with the following layers:\n\n1. **Presentation Layer** (Frontend) - Next.js/React UI\n2. **Application Layer** - FastAPI routes and services\n3. **Domain Layer** - Business logic and use cases\n4. **Data Layer** - Database models and repositories\n5. **AI Provider Layer** - Adapter pattern for AI providers\n6. **Worker Layer** - Background task processing\n7. **Rendering Layer** - FFmpeg-based video rendering\n\n### Adapter Pattern\nAll AI providers use the Adapter Pattern to ensure loose coupling:\n\n`\nTextProvider\n  └── OpenRouterProvider\n       ├── DeepSeekProvider\n       ├── QwenProvider\n       └── LlamaProvider\n\nImageProvider\n  └── PollinationsProvider\n       ├── FLUXProvider\n       └── SDXLProvider\n       └── HFProvider (backup)\n\nVoiceProvider\n  └── KokoroProvider\n       └── PiperProvider (backup)\n`\n\n## Project Structure\n`\ncartoon-studio-ai/\n├── frontend/           # Next.js + React + TS + Tailwind + Zustand\n│   ├── app/           # Next.js app router pages\n│   ├── components/    # Reusable React components\n│   ├── lib/           # Utility functions and API types\n│   ├── hooks/         # Custom React hooks\n│   ├── store/         # Zustand stores\n│   ├── types/         # TypeScript type definitions\n│   └── styles/        # Global styles and Tailwind config\n├── backend/           # FastAPI + Python\n│   ├── main.py        # Application entry point\n│   ├── api/v1/      # Version 1 API routes\n│   ├── core/        # Core configuration (settings, DB)\n│   ├── models/      # SQLAlchemy database models\n│   ├── services/    # Business logic services\n│   └── workers/     # Background task workers\n├── database/          # Database setup and models\n│   ├── migrations/   # SQLAlchemy migrations\n│   └── seeds/        # Database seeds\n├── assets/            # Stored assets\n│   ├── characters/   # Character images\n│   ├── backgrounds/  # Background images\n│   ├── voices/       # Generated audio files\n│   ├── effects/      # Sound effects\n│   └── music/        # Background music\n├── projects/          # Project files\n├── renders/           # Rendering outputs\n├── exports/           # Exported MP4 videos\n├── docs/              # Documentation\n├── prompts/           # AI prompt templates\n├── tests/             # Test suites\n└── README.md          # This file\n`\n
## API Routes\n\n### Projects\n- GET /api/v1/projects - List all projects\n- POST /api/v1/projects - Create a new project\n- GET /api/v1/projects/{id} - Get a project\n\n### Episodes\n- GET /api/v1/episodes - List all episodes\n- POST /api/v1/episodes - Create a new episode\n- GET /api/v1/episodes/{id} - Get an episode\n\n### Scenes\n- GET /api/v1/scenes - List all scenes\n- POST /api/v1/scenes - Create a new scene\n- GET /api/v1/scenes/{episode_id} - Get scenes for an episode\n\n### Characters\n- GET /api/v1/characters - List all characters\n- POST /api/v1/characters - Create a new character\n- GET /api/v1/characters/{episode_id} - Get characters for an episode\n\n### Backgrounds\n- GET /api/v1/backgrounds - List all backgrounds\n- POST /api/v1/backgrounds - Create a new background\n\n### Voices\n- GET /api/v1/voices - List all voices\n- POST /api/v1/voices - Create a new voice\n\n### Assets\n- GET /api/v1/assets - List all assets\n- POST /api/v1/assets - Create a new asset\n\n### Renders\n- GET /api/v1/renders - List all renders\n- POST /api/v1/renders - Create a new render\n- GET /api/v1/renders/{episode_id} - Get render for episode\n\n### Providers\n- GET /api/v1/providers - List configured AI providers\n- POST /api/v1/providers - Configure an AI provider\n\n### Settings\n- GET /api/v1/settings - Get application settings\n- POST /api/v1/settings - Update application settings\n
